# OPSIGNE site

Landing page, French (`index.html`) and English (`en/index.html`), with a working in-browser demo of guided procedure execution, a tamper-evident (hash-chained) log, grounded Q&A that refuses when it cannot answer, and a downloadable report.

**All data is fictional. This is a demo, not a safety system.** No compliance claims are made.

## Open it
- Double-click `index.html` (works from `file://`), or run `python3 -m http.server 8000` in this folder, or drop the folder on any static host.
- No server code, no network requests, no cookies, no storage. Both pages carry a strict CSP meta tag.

## Layout
- `index.html`, `en/index.html`, `css/site.css`, `robots.txt`: generated by `python3 _build_pages.py` (copy and templates live in that file).
- `js/`: `sha256.js chain.js qa.js report.js engine.js demo.js boot.js mop-data.js` (sources) and `bundle.js` (generated, what the pages load).
- `data/`: `mop-ups-017.json` (fictional procedure) and `mop-ups-017.fr.json` (French rendering).
- `logo/`: logo set, PNG exports and favicon.
- `test/`: Node unit tests. `e2e/`: Playwright specs. `tools/`: contrast checker, data builders, reference runner for parity.

## Tests
Node 22 or later.
- Unit, parity and refusal tests: `node --test test/*.test.js`. The parity tests compare the browser engine with a Python reference implementation; point `OPSIGNE_PY` at it if you have it.
- Contrast: `python3 tools/contrast.py` (reads the CSS variables).
- Browser tests (Playwright, English and French at three viewport sizes): serve the folder and run `npx playwright test` with `PW_SITE_DIR` pointing at it. Screenshots go to `SHOTS_DIR` (default: a temp folder).

## How Q&A refuses
`js/qa.js` has two modes. `improve:false` is a faithful port of the reference implementation. `improve:true` is what the demo uses: after TF-IDF retrieval, the question's key words must each be stated by the answering step itself (same word family or a small curated synonym), and intent phrases (how long, who, how many, why, part number) need a matching fact in the step. Otherwise the answer is refused (`attribute_not_in_step`). Some phrasings can still be answered wrongly when two covered words appear in one step but are unrelated; the page says so under the question box.
